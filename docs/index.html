03 · INSTALL

Running in under a minute.

Quicky ships as a classic drag-to-Applications DMG. It is not Apple-notarized yet, so first launch takes one extra click.

1

Download the DMG

Grab the latest Quicky.dmg from GitHub Releases and open it.

2

Drag to Applications

Drop Quicky.app onto the Applications shortcut inside the DMG window.

3

Approve first launch

Run the bundled First Launch Quicky.command, or Control-click the app and choose Open. This only clears Gatekeeper quarantine.

4

Allow Screen Recording

Enable Quicky once in System Settings → Privacy & Security → Screen & System Audio Recording, then hit Refresh in the app.

FIRST LAUNCH · TERMINAL ALTERNATIVE 
# prefer the command line? same result:
$ xattr -dr com.apple.quarantine \
    /Applications/Quicky.app
$ open /Applications/Quicky.app

# build & run from source instead:
$ git clone https://github.com/gianpmarc/Quicky.git
$ cd Quicky && ./script/build_and_run.sh

# requirements: macOS 13+ · Swift 5.9+
04 · PRIVACY

Your pixels never leave your Mac.

No accounts, no telemetry, no cloud sync. Quicky is a native Swift app that writes files to your disk — and that's the whole story.

  • Local vault only. Captures live in ~/Pictures/Quicky as regular files you fully control.
  • Silent permission checks. Refresh re-checks Screen Recording without re-prompting you.
  • Open source, MIT. Every line auditable on GitHub — build it yourself if you prefer.
